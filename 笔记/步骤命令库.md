- `cd /etc/yum.repos.d` 进入目录

- `curl -o CentOS-Base.repo https://mirrors.aliyun.com/repo/Centos-7.repo` 从阿里云下载Base镜像配置文件
  
- `yum clean all`清理缓存
  
- `yum makecache`重建缓存

- `yum install -y yum-utils`安装必要的yum的扩展组件

- `yum-config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo`由于 Docker 不在 base 源中，需要添加源

- `yum list docker-ce --showduplicates`列出 yum 源中所有可用的 Docker 版本
  - 简化版 `yum list docker-ce --showdup`

- `sudo yum install -y docker-ce-<VERSION_STRING> docker-ce-cli-<VERSION_STRING> containerd.io`其中`<VERSION_STRING>`为你要安装的版本号

- `mkdir -p /etc/docker`创建docker配置目录

- `vim /etc/docker/daemon.json`进入镜像源配置文件

- 写入镜像源 
    ```
    {
      "registry-mirrors": 
        "https://docker.1ms.run"
    }
   ``` 

- `systemctl daemon-reload` 重启配置

- `systemctl restart docker` 重启docker

- `docker run hello-world` 若返回 `Hello from Docke!` 及表示配置成功

- `docker pull thingsboard/tb-postgres` ThingsBoard 官方 Docker Hub 的标准镜像

- 创建存放数据文件的地方
  - `mkdir -p ~/.mytb-data` 创建一个存放数据的文件夹
  - `mkdir -p ~/.mytb-logs` 创建一个存放日记的文件夹
  - `sudo chown -R 799:799 ~/.mytb-data` 修改目录权限，让容器内的用户有权限写入
  - `sudo chown -R 799:799 ~/.mytb-logs` 修改目录权限，让容器内的用户有权限写入

- `docker network create -d bridge tb-net`创建docker网络

```
docker run -d \
```
