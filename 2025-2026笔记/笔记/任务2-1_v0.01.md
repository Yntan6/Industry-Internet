### 配置yum-base镜像

- `cd /etc/yum.repos.d` 进入目录
- `mv CentOS-Base.repo CentOS.repo.backup` 对文件CentOS-Base.repo备份
- 从阿里云下载Base镜像配置文件
   `curl -o CentOS-Base.repo https://mirrors.aliyun.com/repo/Centos-7.repo` 或者使用华为云 `http://mirrors.huaweicloud.com/repository/conf/CentOS-7-anon.repo`
   
   这个*CentOS-Base.repo*是保存到本地的文件名
    - `curl` 是从指定url下载文件
    - `-o` 是指定下载内容的本地保存文件名，紧跟的 `CentOS-Base.repo` 就是本地文件名
    - `https...` 是下载地址
- `yum clean all`清理缓存
- `yum makecache`重建缓存

### 配置yum-epel镜像

### 安装docker
- 确保系统上没有docker
---
1. 安装必要的依赖包：
   - `sudo yum install -y yum-utils device-mapper-persistent-data lvm2`安装yum工具和证书相关包，用于配置docker源
     - `sudo`超级用户权限
     - `yum`管理工具
     - `install` `yum`的子命令，表示安装操作
     - `-y` 安装过程中自动回答
     - `yum-utils` `yum`的扩展工具集
     - `device-mapper-persistent-data` 映射支持的工具和内核模块，用于管理设备映射的元数据，防止映射丢失
     - `lvm2` 逻辑卷管理器的核心软件包

2. 配置yum的源，由于 Docker 不在 base 源中，需要添加源
- `sudo yum-config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo`添加阿里云的镜像

3. 查看可用的 Docker 版本
- `yum list docker-ce --showduplicates | sort -r`先列出 yum 源中所有可用的 Docker 版本
  - `yum` 管理工具
  - `list` `yum` 的子命令 列表
  - `docker-ce` 要查询的软件包名称
  - `--showduplicates` 显示所有重复版本,列出软件包的所有可用版本
  - `|` 管道操作符：将前一个命令的输出作为后一个命令的输入
    - 前：`yum list docker-ce --showduplicates` 的输出
    - 后：作为 `sort -r` 的输入
    - 实现命令的链式处理
  - `sort` 排序命令
  - `-r` reverse（反向）：降序排列

4. 安装docker
- `sudo yum install -y docker-ce-<VERSION_STRING> docker-ce-cli-<VERSION_STRING> containerd.io`其中`<VERSION_STRING>`为你要安装的版本号
  - `sudo`超级用户权限
  - `yum`管理工具
  - `install` `yum`的子命令，表示安装操作
  - `-y` 安装过程中自动回答
  - `docker-ce-<VERSION_STRING>` 引擎
  - `docker-ce-cli-<VERSION_STRING>` 管理工具
  - `containerd.io` 容器管理

5. 配置docker的镜像源
- 创建docker配置目录
  - `mkdir -p /etc/docker`
- 写入镜像源：
  - `vim /etc/docker/daemon.json`通过vim进入这个json文件
   ```
    {
      "registry-mirrors": [
        "https://hub-mirror.c.163.com",
        "https://mirror.baidubce.com",
        "https://docker.mirrors.ustc.edu.cn"
      ]
    }
   ``` 
  - `systemctl daemon-reload` 重启配置
  - `systemctl restart docker` 重启docker

6. 验证镜像源
- `docker run hello-world` 若返回 `Hello from Docke!` 及表示配置成功

7. 拉取thingsboard镜像
- `docker pull swr.cn-north-4.myhuaweicloud.com/ddn-k8s/docker.io/thingsboard/tb-postgres:latest` 这个是使用华为云的镜像，官方的镜像源为：`docker.io/thingsboard/tb-postgres:latest`
- 可以使用 `docker images` 查看是否拉取成功

8. 创建存放数据文件的地方
- `mkdir -p ~/.mytb-data` 创建一个存放数据的文件夹
- `mkdir -p ~/.mytb-logs` 创建一个存放日记的文件夹
- `sudo chown -R 799:799 ~/.mytb-data` 修改目录权限，让容器内的用户有权限写入
- `sudo chown -R 799:799 ~/.mytb-logs` 修改目录权限，让容器内的用户有权限写入
